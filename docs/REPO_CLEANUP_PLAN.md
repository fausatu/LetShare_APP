# Repo Cleanup Plan

## Goal
Make the GitHub repository clean, professional, and safe to publish.

## Steps
1. Remove sensitive files and secrets from the repository history.
2. Keep only needed runtime and source files in the public repo.
3. Add environment templates and clear setup instructions.
4. Split work into small feature-based commits.
5. Add GitHub issue and PR templates.
6. Configure deployment secrets for IONOS.

## Priority order
- Security
- Documentation
- Repository hygiene
- Deployment automation
